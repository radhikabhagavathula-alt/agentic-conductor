# Fact-Check Report Formatting

When presenting a completed fact-check, always structure it exactly as follows:

## [Topic Title]

**Claim:** [state the claim in one sentence]

**Verdict:** [TRUE ✅ / FALSE ❌ / PARTIALLY TRUE ⚠️ / UNCERTAIN ❓] — [confidence: High/Medium/Low]

**Explanation:** [2-3 sentences max explaining the verdict]

**Sources:**
- [source 1 as markdown link]
- [source 2 as markdown link]

Rules:
- Never skip the confidence level.
- If the claim has multiple sub-parts, verify each separately and show a small table instead of a single verdict.
- Keep the explanation under 3 sentences — link to sources for depth, don't restate the whole research.
